# My Portfolio

This is my portfolio powered by SvelteKit, TailwindCSS and flowbite elements. The page is running via GitHub pages since it is a static webpage.

## Developing

Once you've created a project and installed dependencies with `npm install` (or `pnpm install` or `yarn`), start a development server:

```sh
npm run dev
```

## Building

To create a production version of your app:

```sh
npm run build
```
